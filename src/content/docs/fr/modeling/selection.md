## Méthodes

| Action | Effet |
| :--- | :--- |
| Clic | Sélectionne l'objet sous le curseur |
| `Ctrl` + clic | Ajoute l'objet à la sélection, ou l'en retire s'il y est déjà |
| Glisser avec le bouton gauche | Sélection par rectangle |
| `Ctrl+A` | Tout sélectionner |
| `Échap` | Quitte la commande en cours et vide la sélection |

## Sélection multiple

Avec plusieurs objets sélectionnés, **Propriétés** affiche les valeurs communes. Une modification
s'applique à tous les objets compatibles et s'annule en une seule fois avec `Ctrl+Z`.

## Isoler et masquer

| Raccourci | Effet |
| :--- | :--- |
| `I` | Isoler la sélection |
| `H` | Masquer la sélection |
| `Alt+H` | Tout afficher |
