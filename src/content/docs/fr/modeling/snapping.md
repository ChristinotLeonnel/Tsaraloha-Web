## Réglages

| Raccourci | Fonction |
| :--- | :--- |
| `F3` | Accrochage aux objets : nœuds, extrémités, milieux |
| `S` | Magnétisme de la grille |

Le point accroché est signalé par un marqueur sous le curseur. Un clic place le point exactement à
cet endroit.

> [!TIP]
> Désactivez temporairement l'accrochage aux objets pour cliquer dans une zone dense.
