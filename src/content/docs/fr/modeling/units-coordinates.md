## Unités

| Grandeur | Unité |
| :--- | :--- |
| Longueur | m |
| Force | kN |
| Moment | kN·m |
| Charge linéique | kN/m |
| Module d'élasticité | Pa dans le modèle, kN/m² dans les résultats |

## Repère global

Le repère global est direct. **Z est vertical vers le haut** : la gravité agit selon −Z.

## Annuler et rétablir

`Ctrl+Z` annule la dernière opération et `Ctrl+Y` la rétablit.
