## Nouveau projet

- Depuis le centre de démarrage, choisissez un nouveau projet.
- Dans TSA, utilisez **Fichier > Nouveau** ou `Ctrl+N`. TSA propose d'enregistrer le projet en cours.

Un projet vide contient une grille et un plan de travail horizontal. Vous pouvez commencer à dessiner
immédiatement.

## Enregistrer et ouvrir

| Action | Raccourci |
| :--- | :--- |
| Ouvrir un projet `.tsa` | `Ctrl+O` |
| Enregistrer | `Ctrl+S` |
| Enregistrer sous | `Ctrl+Maj+S` |

Le projet est enregistré dans un seul fichier `.tsa`. Voir [Fichiers de projet](/docs/getting-started/files).

## Créer un projet depuis un fichier IFC

**Fichier > Importer IFC** crée un projet à partir d'un fichier IFC. Cette fonction est expérimentale :
voir [Import et export IFC](/docs/bim/ifc).
