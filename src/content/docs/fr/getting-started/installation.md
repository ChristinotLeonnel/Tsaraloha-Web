## Disponibilité

Aucun installateur public n'est publié pour l'instant. Les versions publiées apparaîtront sur la page
[Téléchargements](/downloads) et sur la page des publications du dépôt GitHub de TSA.

> [!IMPORTANT]
> Ne téléchargez TSA que depuis ces deux sources. Aucun autre site n'est autorisé à distribuer le logiciel.

## Après l'installation

1. Lancez TSA. Le centre de démarrage s'ouvre.
2. Créez un projet ou ouvrez un fichier `.tsa` existant.
3. Au premier calcul, acceptez le téléchargement d'OpenSees si TSA le propose.
