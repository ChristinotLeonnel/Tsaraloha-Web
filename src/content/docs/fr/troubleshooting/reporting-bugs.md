## Où signaler

Ouvrez un ticket sur la page des tickets du dépôt GitHub de TSA, accessible depuis la page
[Support](/support).

## Informations utiles

1. Version de TSA, visible dans **Aide > À propos**.
2. Version de Windows.
3. Étapes exactes pour reproduire le problème.
4. Résultat attendu et résultat obtenu.
5. Si possible, un fichier `.tsa` minimal qui reproduit le problème.

> [!WARNING]
> Ne joignez pas de fichier contenant des données confidentielles de vos projets.
