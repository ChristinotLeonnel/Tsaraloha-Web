## Lancer

- `F5` ou **Analyse > Calcul statique**.
- La fenêtre **Analyse structurelle** permet de choisir le moteur, le type de calcul et la portée.

## Portée

| Portée | Contenu calculé |
| :--- | :--- |
| Modèle complet | toutes les barres |
| Sélection | les barres sélectionnées |
| Axe de grille | les barres d'un axe, en 2D |
| Niveau | les barres d'un étage |
| Plan de travail | les barres du plan actif |

Le calcul s'exécute en arrière-plan. Le journal s'affiche dans la console.

## Résultats périmés

Toute modification du modèle après un calcul rend les résultats périmés. Relancez le calcul.
