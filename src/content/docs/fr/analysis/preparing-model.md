## Liste de contrôle

1. Toutes les barres ont une section et un matériau.
2. La structure a assez d'appuis pour être stable.
3. Aucune barre n'a une longueur nulle.
4. Les nœuds confondus sont fusionnés.
5. Les charges sont dans les bons cas et les combinaisons sont définies.

TSA valide le modèle avant le calcul et liste les erreurs et les avertissements.
