## Onglet Résultats

| Commande | Affichage |
| :--- | :--- |
| Déformée 3D | forme déformée amplifiée |
| Déplacements | déplacements des nœuds |
| Diagrammes 3D | efforts N, V, M le long des barres |
| Réactions | réactions d'appui |
| Panneau Résultats | tableaux et synthèse |

Sélectionnez une barre : **Propriétés** affiche ses efforts, avec le moteur et la portée utilisés.

## Conventions

L'effort normal N est positif en traction. Les efforts sont exprimés dans le repère local des barres.
