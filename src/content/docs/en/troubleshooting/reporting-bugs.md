## Where to report

Open an issue on the TSA GitHub repository, linked from the [Support](/support) page.

## Useful information

1. TSA version, shown in **Help > About**.
2. Windows version.
3. Exact steps to reproduce the problem.
4. Expected and actual result.
5. If possible, a minimal `.tsa` file that reproduces the problem.

> [!WARNING]
> Do not attach files containing confidential project data.
