TSA lets you draw a 3D structure (nodes, beams, columns, trusses, cables), assign sections, materials
and supports, apply loads, and analyse it with a finite element engine.

## Feature status

| Area | Status | Note |
| :--- | :--- | :--- |
| Member modeling | Available | Viewport or dialog input |
| Slabs and walls | Modeling only | **Not included in the analysis** |
| Nodal and member loads | Available | Uniform, trapezoidal, point, nodal couple |
| Surface loads | Planned | |
| Load cases, combinations, self-weight | Available | |
| 3D linear static analysis (OpenSees 3.8.0) | Available | External executable |
| Nonlinear static analysis | Experimental | |
| Plane frame engine (Custom2D) | Experimental | |
| Dynamic analysis | Not available | Removed from the current version |
| Surface meshing | Planned | Estimate only |
| PDF and HTML calculation report | Available | |
| IFC import and export | Experimental | Partial export |

## Platform

TSA runs on **Windows 10 or 11, 64-bit**. No Linux or macOS version is published.
