No public installer has been published yet. Published versions will appear on the
[Downloads](/downloads) page and on the releases page of the TSA GitHub repository.

> [!IMPORTANT]
> Only download TSA from these two sources.

On the first analysis, TSA offers to download OpenSees 3.8.0 from the official OpenSees website if it
is missing.
